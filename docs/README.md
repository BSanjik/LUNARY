# Документация LUNARY

Добро пожаловать в центр документации проекта LUNARY - платформы для планирования мероприятий с использованием ИИ.

## 📋 Обзор документации

### 🏗️ [Архитектура](./architecture.md)
Подробное описание микросервисной архитектуры системы:
- Архитектурные принципы и подходы
- Компоненты системы и их взаимодействие
- Потоки данных между сервисами
- Планы масштабирования и развития

### 🛠️ [Технологический стек](./tech-stack.md)
Полный обзор используемых технологий с обоснованием выбора:
- Frontend: Flutter, Dart
- Backend: Go, Gin, PostgreSQL, Docker
- Инфраструктура и мониторинг
- Планируемые технологии и roadmap

### ⚙️ [Установка и настройка](./setup.md)
Пошаговые инструкции для разработчиков:
- Системные требования
- Быстрый старт с Docker Compose
- Настройка локальной разработки
- Решение типичных проблем

### 📡 [API спецификация](./api-spec.md)
Полная документация REST API всех микросервисов:
- Auth Service API (регистрация, авторизация)
- Scenario Service API (поиск сценариев, отзывы)
- Планируемые API (User, Ad, Media, Notification)
- Примеры запросов и ответов

### 📊 [Диаграммы](./diagrams/)
Визуальные схемы архитектуры в формате Mermaid:
- `architecture-overview.mmd` - общая архитектура
- `data-flows.mmd` - потоки данных
- `database-schema.mmd` - схема БД

## 📁 Структура проекта

```
LUNARY/
├── services/              # Бэкенд микросервисы
│   ├── api-gateway/       # API Gateway (8080)
│   ├── auth-service/      # Аутентификация (8081)
│   ├── scenario-service/  # Сценарии мероприятий (8082)
│   └── ...               # Другие сервисы
├── frontend/             # Flutter приложение
├── docs/                 # Документация (здесь)
├── deploy/               # Конфигурации развертывания
└── docker-compose.yml    # Оркестрация контейнеров
```

## 🎯 Статус проекта

### MVP (готово) ✅
- **API Gateway** - маршрутизация, аутентификация, rate limiting
- **Auth Service** - регистрация, авторизация, JWT токены
- **Scenario Service** - поиск сценариев, система отзывов
- **PostgreSQL** - база данных с миграциями
- **Docker Compose** - контейнеризация и оркестрация

### В разработке 🔄
- **User Service** - управление профилями пользователей
- **Flutter Frontend** - мобильное приложение
- **CI/CD Pipeline** - автоматизация развертывания

### Планируется 📋
- **Ad Service** - рекламные объявления
- **Media Service** - загрузка и хранение файлов
- **Notification Service** - push-уведомления и email
- **Web Admin Panel** - административная панель

## 🔄 Обновление документации
