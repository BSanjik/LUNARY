# Диаграммы LUNARY

Эта папка содержит архитектурные диаграммы проекта LUNARY в формате Mermaid.

## Файлы диаграмм

### 1. `architecture-overview.mmd`
**Общая архитектура системы**
- Показывает все компоненты системы
- Связи между микросервисами
- Статус разработки каждого компонента

### 2. `data-flows.mmd`
**Потоки данных и взаимодействия**
- Sequence диаграмма основных операций
- Регистрация и авторизация пользователей
- Поиск сценариев и отправка отзывов

### 3. `database-schema.mmd`
**Схема базы данных**
- ER диаграмма всех таблиц
- Текущие таблицы (MVP)
- Планируемые таблицы (future)
- Связи между таблицами

## Как просматривать диаграммы

### VS Code (рекомендуется)
1. Установите расширение "Mermaid Preview"
2. Откройте `.mmd` файл
3. Нажмите `Ctrl+Shift+P` → "Mermaid: Preview"

### Онлайн редактор
1. Откройте https://mermaid.live/
2. Скопируйте содержимое `.mmd` файла
3. Вставьте в редактор

### GitHub/GitLab
Диаграммы автоматически отображаются в README файлах:

\`\`\`mermaid
// содержимое .mmd файла
\`\`\`

## Экспорт диаграмм

### В изображения
```bash
# Установить mermaid-cli
npm install -g @mermaid-js/mermaid-cli

# Экспорт в PNG
mmdc -i architecture-overview.mmd -o architecture-overview.png

# Экспорт в SVG
mmdc -i data-flows.mmd -o data-flows.svg

# Экспорт в PDF
mmdc -i database-schema.mmd -o database-schema.pdf
```

### В документацию
Диаграммы можно встраивать в Markdown документы:

```markdown
## Архитектура

```mermaid
graph TB
    // содержимое диаграммы
```
```

## Обновление диаграмм

При изменении архитектуры обновляйте соответствующие диаграммы:

1. **Новый микросервис** → обновить `architecture-overview.mmd`
2. **Новый API endpoint** → обновить `data-flows.mmd`
3. **Новая таблица БД** → обновить `database-schema.mmd`

## Цветовая схема

### Архитектурная диаграмма
- 🟢 **Зеленый** - готовые компоненты (MVP)
- 🟡 **Желтый** - в разработке
- 🟠 **Оранжевый** - планируются
- 🔵 **Синий** - база данных
- 🟣 **Фиолетовый** - API Gateway

### Диаграмма потоков
- **Стрелки** показывают направление запросов
- **Пунктирные стрелки** - ответы
- **Примечания** - группировка операций

### Схема БД
- **PK** - Primary Key
- **FK** - Foreign Key
- **JSON** - JSON поля для гибкости
- **CHECK** - ограничения значений
